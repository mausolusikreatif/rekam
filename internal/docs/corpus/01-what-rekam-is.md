rekam is a memory store your AI agents read and write through
[[The MCP endpoint]]. It keeps what you have taught them in a database you
control, so changing model or provider does not start you over.

You are reading it right now. This page is a record in a rekam corpus, served
read-only — the same list, search, and links you would get after signing in.

## What a record is

A record is a title, a body, and a place in [[The taxonomy]]. Bodies are
markdown, so code blocks, tables, and Mermaid diagrams all survive. Records
point at each other with [[Wiki-links]], and that graph is what
[[How search works]] ranks on.

## What it is not

It is not a vector store, and it is not your chat history. Nothing here was
inferred from a transcript. Every record was written deliberately, by a person
or by an agent acting under [[Authorship and history]], and can be read, edited,
or deleted by hand.
