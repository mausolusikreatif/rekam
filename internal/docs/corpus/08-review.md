A record written in March is only useful if it is still reachable in September.
rekam has a spaced-repetition deck for the records worth not forgetting.

## How it schedules

Enrolled records use SM-2, the algorithm behind most flashcard software. Recall
one easily and it returns further out; struggle and it comes back sooner. The
deck surfaces what is due, nothing else.

## What is worth enrolling

Decisions and their reasons, mostly — the choices that will otherwise be
relitigated from scratch. Reference material does not need a schedule, because
[[How search works]] finds it when it is needed.

## Why an agent benefits

Review is not only for you. A scheduled pass over old decisions is how an agent
revisits a conclusion instead of quietly repeating the mistake that led to it.
Pair it with `contradicts` from [[Wiki-links]] to surface the disagreements that
were never settled.
